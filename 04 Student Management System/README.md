# Expense Tracker

A simple menu-driven Expense Tracker application built using Python.

## Features

- Add new expenses
- Store expenses in a CSV file
- View all recorded expenses
- Calculate total amount spent
- Display category-wise spending summary
- Validate date and amount inputs
- Handle invalid input gracefully
- Use file handling for persistent data storage

## Expense Details

Each expense contains:

- Date
- Category
- Amount
- Note (optional)

## Technologies Used

- Python
- CSV Module
- File Handling
- Exception Handling
- Functions
- Loops
- Dictionaries

## How to Run

Run the following command:

```bash
python expense_tracker.py
```
